# Docs

Единая директория для всей проектной документации.

## Структура

- `plans/` — плановые документы проекта.
- `sources/` — исходные материалы (PDF/внешние артефакты).
- `standards/` — правила архитектуры, код-стиля и тестирования.
- `templates/` — шаблоны для ежедневной работы.
