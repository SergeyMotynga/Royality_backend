# План разработки FinGuru

## Контекст

Проект переведен на домен FinGuru (финансовый ассистент) и ведется в этом векторе.

Каноничная полная версия плана: [BACKEND_DEVELOPMENT_PLAN.md](./BACKEND_DEVELOPMENT_PLAN.md).

## Фокус MVP

- AI-чат с безопасными ограничениями.
- Финансовые цели.
- Симуляторы.
- Викторины.
- Персональные рекомендации.
- Контур согласий и аудита.

## Архитектурный принцип

- Слои: `api/endpoints -> services -> validators -> crud`.
- Разделение `public` и `admin` по правам и доменам.

## Definition of Done (MVP)

- Реализованы пользовательский и админский контуры API.
- Соблюдаются policy-ограничения AI-контура.
- Критичные сценарии работают end-to-end.
- Миграции стабильны (`alembic upgrade head`).
- Тесты проходят в CI.

## Версионирование

- API публикуется как `/api/v1/...`.
- Breaking-изменения только через новую версию.
